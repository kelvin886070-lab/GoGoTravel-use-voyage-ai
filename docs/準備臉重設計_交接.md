## 2. 生命週期脊椎（五段）現況 — 已實作，勿誤改

五段：規劃 → 準備 → 前夕 → 旅途 → 回憶。時間驅動偵測當前段。

**時間軸（daysToDep = 出發前天數）：**

- `>30 天`：整條脊椎「**變暗**」——所有節點中性、無「現在」綠光；規劃/準備仍可點（不施壓，早鳥自便）。
- `30–21 天`：**規劃**亮綠「現在」。
- `21–3 天`：**準備**亮綠「現在」。
- `≤3 天`：**前夕**（時間鎖，點擊跳溫柔 toast）。
- 旅程中 = 旅途；結束後 = 回憶。

**兩個獨立門檻，別搞混：**

- 階段分界（`computeStage`）：前夕 ≤3、準備 ≤21、規劃 >21。
- 脊椎「啟動/變暗」門檻：`ACTIVATE_DAYS = 30`。

**實作位置：**

- `src/views/ItineraryView/StageSpine.tsx`：`computeStage()`、`ACTIVATE_DAYS`、四種節點視覺態
  （已選=ink、走過=淺綠打勾、當前=綠環+「現在」、可進但非當前=中性 outline、上鎖=虛線+鎖）。
- `src/views/ItineraryView/ItineraryView.tsx`：`spineActivated = currentStageIdx>=1 || daysToDep<=30`；
  傳 `current={spineActivated ? currentStageIdx : -1}`。`current=-1` 時全節點落中性態＝變暗。
- 規劃/準備**永不上鎖**；只有前夕/旅途/回憶（i>=2）時間鎖，點擊回呼 `onLockedTap` 跳票券風 toast（`NOT YET`）——**非「解鎖」話術**。

**測法**：改行程 startDate。40 天後看變暗；25 天後看規劃亮；15 天後看準備亮；2 天後看前夕鎖 toast。

## 3. 這次的對象：準備臉 PrepareFace

檔案：`src/views/ItineraryView/StageFaces.tsx` 的 `PrepareFace`。

**現況結構（由上到下）：**

1. 就緒環 `ready/4` ＋「出發前 N 天」＋心情句（開始準備了 / 踏實累積中 / 快準備好了！）。
2. 「最該補」英雄卡（機票或住宿優先，按鈕：已備了 / 去補齊）。
3. 四項清單：機票 / 住宿 / 文件 / 行李打包。done 顯示旋轉「OK」章（可點撤章）；未 done 顯示「已備」(ghost) ＋「補齊」(dashed)。
4. Footer：「機票＋住宿蓋章，就進前夕」。

**props**：`{ trip, daysToDep, onMarkReady(k, v), onFix(k) }`，`k ∈ 'flight'|'hotel'|'docs'|'pack'`。

**就緒來源**：`trip.readiness = { flight, hotel, docs, pack }`（明確蓋章，**不靠行程結構偵測**——因為國際線會自動生成 flight 連接活動，用結構偵測會假陽性）。

**onFix 現行行為**（在 ItineraryView `openBooking`）：flight→Google Flights、hotel→Booking.com（都是搜尋 URL，之後換 affiliate deep link 只改這兩行）、docs→保管箱 picker、pack→「即將推出」toast。

## 4. 要做的事：準備臉重設計 mockup（Kelvin 已認可以下 6 點全數納入）

### 必改（優化點）

1. **就緒環別等權**：機票/住宿是關鍵路徑（高價、隨時間漲、晚了訂不到），文件/行李是低風險。
   環只計「訂購類（機票+住宿）」，或拆兩區顯示「訂購 0/2 · 打包 2/2」，讓關鍵路徑視覺獨立。
2. **蓋章即捕捉資料（槓桿最大 → 當視覺主軸）**：機票/住宿的「已備了」升級成輕量捕捉——
   貼確認信截圖或填航班/日期。這份資料同時餵保管箱、並讓**前夕登機證的 FROM/TO/DEPART 自動長出**
   （目前 `trip.origin` 空白顯示「—」，就是這個洞）。不捕捉，readiness 只是裝飾。
3. **消除重複**：英雄卡與下方同一項清單重複顯示、且兩套不一致按鈕。
   把優先項折進清單（高亮首列），或讓英雄卡真的加值（講清為何最急）。

### 加分（有會更好）

4. **把嘮叨變情報（護城河）**：別只寫「缺住宿」，寫「東京週末房價週漲 8% / 早鳥票剩 X 天」。
   呼應商業模式：缺口偵測 → 通知 → 一站式導購。（真實資料源屬下游，mockup 先放靜態示意。）
5. **蓋章即建檔 → 前夕登機證自己長出**：機票蓋章帶日期/起訖點 → 前夕 boarding pass 自動填。
   視覺上蓋章「印出」登機證一角（情緒 payoff ＋資料復用，縫合兩階段）。
6. **蓋章儀式微動效（皮克敏式）**：OK 章落下墨水暈開＋觸覺回饋，環填滿一個滿足 tick。
   Framer Motion（已在用）／Lottie。這是把「打勾清單」變「有溫度準備」的簽名互動。
