## 1. 安全（🔴 最優先，一條都不能漏）
- [ ] 🔴 **API 金鑰零外洩**：Google Places / Gemini 金鑰只存在 Supabase Edge Function（`ai-proxy`）的 server env，前端 bundle／network／git 全都查不到。上架前用 `grep -ri "AIza\|sk-\|GOCSPX" src/ dist/` 掃一遍確認乾淨。
- [ ] 🔴 **Supabase RLS 全表開啟且正確**：`trips`／`wish_items`／`wish_lists`／`bookings`／`cached_searches` 每張表都要有 row-level security，且只能讀寫「自己 user_id」的資料。用另一個帳號實測「拿不到別人的資料」。
- [ ] 🔴 **anon key 權限最小化**：確認前端只用 anon key，service_role key 絕不進前端。
- [ ] 🔴 **Edge Function 的每日額度／濫用防護**：`ai-proxy` 的 `bumpDailyOrLimit`（200/日）在正式流量下是否合理；有沒有 per-user 限額避免單一帳號打爆。
- [ ] 🟠 **CORS 白名單**：Edge Function 只允許正式網域，不要 `*`。
- [ ] 🟠 **輸入驗證**：搜尋字串、清單名稱等做長度／內容上限，避免注入與異常 payload。
