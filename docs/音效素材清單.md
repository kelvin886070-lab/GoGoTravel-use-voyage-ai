# 音效素材清單（Kelvin 挑素材用）

> 用法：Kelvin 找到 wav 後放進 `public/sounds/`（原始檔另備份 `brand-assets/sounds/`），Claude 以 ffmpeg 裁剪對齊動畫長度、轉 96k mp3、統一響度。
> 統一規格：**峰值 -10 ~ -13dB**（家族一致，避免有的刺耳有的聽不見）、mp3 96kbps、單聲道即可、檔案 <25KB。
> 全部走 `services/sounds.ts` 引擎：lazy 預載、永不 throw、受「音效開關」控制（會員中心）。
> 挑選原則：**真實錄音優於合成**；乾淨無環境噪音、無殘響尾巴（我們自己加淡出）；一段只有一個動作。

## C. 播放規則（實作時遵守）

1. **音量分層**：`stamp` > `paper-drop` ≈ `ticket-tear` > `pen-circle` ≈ `eraser` > `pen-write` ≈ `soft-tap`。連續播放的音（`pen-write`）一律更輕。
2. **時機**：聲音在**動作起點**播（紙聲發生在翻的過程中，不是翻完之後）。
3. **不重疊**：同一個使用者動作只播一聲（例：選回程日重繪雙圈時，起點圈靜默）。
4. **連打**：同一音效重播＝rewind 同一個 Audio 實例，不疊加多實例。
5. **開關**：全部受會員中心「翻頁音效」開關控制（未來可改名「音效」）；關閉時完全靜默。
6. **失敗靜默**：自動播放政策擋下、檔案缺失、無 Audio 環境 → 一律靜默，永不 throw、永不阻塞動畫。
7. **觸覺搭配**：`pen-circle`／`check-tick`／翻頁＝輕震一下；`eraser`＝兩下短震；`stamp`＝一下重震（原生打包後換 Capacitor Haptics）。

## D. 素材來源建議

- 免費可商用：Freesound（注意逐一確認授權為 CC0）、Pixabay Sound Effects、BBC Sound Effects（個人/教育授權需確認）。
- 付費一次買斷：Artlist、Epidemic Sound、Soundsnap（商用最保險）。
- **自錄最推薦**（紙筆類音效極容易自錄，且完全無授權疑慮）：手機貼近桌面、安靜房間、錄鋼筆畫圈／橡皮擦／紙張落桌／印章壓下——真實感勝過任何素材庫。

> ⚠️ 授權鐵律：素材一律自產或有明確商用授權；**浮水印素材、來源不明的檔案永不進 repo**（與圖片素材同規）。

全部 peak 正規化到 **−3dBFS**、128kbps。

🔴 **「三個短音」被否決（2026-08-09 Kelvin 實測）**：我原本設計成短音連放三次、音量遞減（1.0／0.63／0.45），
論證是「聽起來像一疊紙被放下」。**實際聽是三次獨立事件，把從容的情緒切碎了。**
➜ 原則：**一個連續的過程，就該用一段連續的聲音**；用多次短音去「模擬」一個過程，
耳朵聽到的是節拍，不是動作。（與「拿起-端詳-放下」那次同一類錯誤：我為想做的效果找了好聽的理由。）

🔴 **裁切踩到的兩個坑**：
1. **找瞬態要掃全長。** paperLand 我第一次只看前 0.9s，把 0.70s 的小峰當成落紙聲——那其實是**手放開紙**的窸窣，真正的落地在 **1.05s、能量大五倍**。只憑局部波形裁切，會得到一聲軟綿綿的摩擦。
2. **`ffmpeg -ss` 之後 pts 仍是原始時間軸**，`afade=t=out:st=0.165` 會落在「早就過去」的位置 → **整段變靜音（實測 −91dB）**，而且 `asetpts` 加在 `-ss` 之後也救不回來。
   正解是**不要用 `-ss`**，改在 filter 鏈裡裁：
   ```bash
   ffmpeg -i in.wav -af "atrim=start=1.015:duration=0.195,asetpts=PTS-STARTPTS,\
   afade=t=in:st=0:d=0.003,afade=t=out:st=0.165:d=0.030" out.wav
   ```

**沿用既有**：`penCircle`（圈選）／`eraser`（取消）——**Kelvin 定案：全表單共用同一個音效，不另外找**；
`paperUnfold`・`paperFold`／`pageTear`（下一步撕票，走 `TicketNextButton`）。

⚠️ **`paperLift` 目前沒有呼叫端**：「拿起」的動作隨 v2 的三拍動畫一起退役了。常數與檔案**刻意保留**，
給 ⑧確認與生成幕的「抽新紙」用（有計畫的保留，不是忘了刪）。

**播放規則（⑥ 特有）**：
- 進場 `paperSettle` **只播一次**（延遲 180ms＝第一張紙開始落的那一刻，音量 0.85）。
- 勾選用 **`tick` 0.9**（專屬音效，與圈選的 `penCircle` 是兩種不同的筆法）、取消用 `eraser` **0.7**。
- 即時手寫回饋、矛盾旁註浮現：**不加音**。那是閱讀，不是操作（與「季節句浮現」同一條）。

🔧 `services/sounds.ts` 的 **`PENDING` 集合**（現已清空）：新增音效時先把代號放進去＝**一律靜默、連 Audio 都不建**，
素材進 `public/sounds/` 再刪掉那一行。為什麼要這張表而不是「檔案不存在自然失敗」：①`preloadPageSounds()`
會對每個 SRC 建 Audio，缺檔會在 console 洗一排 404——那是**假的錯誤訊息**，會讓真的錯誤更難看見；
②有名字沒聲音是一種假按鈕，明確列出來才知道還欠什麼。
